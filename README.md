### 🚀 Sobre mí

Soy **Administrador de Redes y Project Manager** en la Secretaría de Innovación de la Municipalidad de Pilar. Mi enfoque principal es la gestión de infraestructura crítica, monitoreo a gran escala y la seguridad ofensiva. Actualmente, dedico mi tiempo libre a profundizar en el mundo de la **Ciberseguridad**.

- 🔭 **Proyectos actuales:** Liderando la implementación de infraestructura tecnológica y sistemas de seguridad urbana para 2026.
- ⚡ **Especialidad:** Automatización de infraestructuras con Python y monitoreo avanzado (Zabbix/PRTG).
- 🐧 **Entorno:** Usuario y administrador avanzado de **Arch Linux**.
- 🔐 **Objetivo:** Aplicar metodologías de Ethical Hacking para robustecer infraestructuras públicas.
